# UI design HTML mocks (Codex)

Mirrors **`.cursor/rules/ui-design-mockups.mdc`** and **`.claude/rules/ui-design-mockups.md`**. Follow the Claude file for full workflow; keep all three aligned when editing.

When asked to **create or update user-visible UI design** in **`docs/design/`**:

1. Deliver static **HTML mocks** under **`docs/design/mockups/`** first.
2. For additions to an existing UI, update the current UI as the example when possible; keep its real chrome/tokens/layout and show the proposed change in place.
3. Link mocks from the authoritative design doc.
4. Only then open implementation tickets or write production UI code.

Full workflow: **`.claude/rules/ui-design-mockups.md`**.
